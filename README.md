A tiny browser game — Star Catcher, a basket catching falling stars — built by an AI coding agent from one prompt, and the short video about it that the agent made for the make.fun bounty "The agent builds a game from one prompt". The one prompt was: "Build a tiny browser game: a basket catches falling stars. Arrow keys move the basket, each star caught scores a point, three missed stars ends the game."

Play it: open `game/index.html` in a browser (or serve the `game/` folder). Arrow keys or drag to move the basket, catch the stars, three misses ends the game, R restarts.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
